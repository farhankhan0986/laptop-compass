# Laptop Compass

A modern web application built to help users navigate and find the perfect laptop based on their needs. 

This project was bootstrapped using a Lovable template featuring **TanStack Start**, **TypeScript**, and **Vite**, utilizing **Bun** as the package manager and runtime.

---

## 🚀 Tech Stack

*   **Framework:** [TanStack Start](https://tanstack.com/router/v1/docs/start/overview) (Full-stack React framework)
*   **Language:** [TypeScript](https://www.typescriptlang.org/)
*   **Build Tool:** [Vite](https://vitejs.dev/)
*   **Package Manager:** [Bun](https://bun.sh/)
*   **Styling & UI:** Tailwind CSS & shadcn/ui (configured via `components.json`)
*   **Code Quality:** ESLint & Prettier

---

## 🛠️ Getting Started

### Prerequisites

Ensure you have [Bun](https://bun.sh/) installed on your local machine.

### Installation

1. Clone the repository:
```bash
   git clone [https://github.com/farhankhan0986/laptop-compass.git](https://github.com/farhankhan0986/laptop-compass.git)
   cd laptop-compass
Install dependencies:

Bash
   bun install
Development
To start the local development server:

Bash
bun run dev
Open http://localhost:3000 (or the port specified in your terminal) to view the application in your browser.

Building for Production
To build the application for production deployment:

Bash
bun run build
📁 Project Structure
.lovable/ - Lovable platform configuration and tracking changes.

src/ - Application source code including components, routes, and logic.

src/index.tsx - Main application entry point.

public/ - Static assets like images, icons, and fonts.

components.json - Configuration file for shadcn/ui components.

vite.config.ts - Vite configuration environment.
